# 🌐 P02 · Web corporativa

## 📖 Breu descripció

### Introducció

A la **Tasca 8** vau triar la proposta de pàgina web que presentareu als responsables de **FoodLogístics** per substituir la seva pàgina actual.

Ara és el moment de desplegar aquesta solució perquè pugui ser visualitzada i avaluada pel client.

---

# 🎯 Objectiu de l'activitat

L'objectiu d'aquesta tasca és:

* Preparar el repositori del projecte web.
* Afegir la documentació corresponent.
* Publicar la proposta web mitjançant **GitHub Pages**.
* Permetre que el client pugui visualitzar la solució proposada.

---

# 🛠️ Desenvolupament de l'activitat

## 1️⃣ Crear el repositori

Creeu el repositori corresponent a:

```text
web_projecte7
```

L'enllaç es troba al Moodle de **Projecte Intermodular**, dins de l'activitat:

> P02 · Web corporativa

---

## 2️⃣ Clonar el repositori

Cloneu el repositori al vostre equip local.

```bash
git clone <URL_DEL_REPOSITORI>
```

---

## 3️⃣ Completar el README

Actualitzeu el fitxer:

```text
README.md
```

incloent la informació rellevant del projecte.

---

## 4️⃣ Crear la carpeta docs

Dins del repositori, creeu la següent estructura:

```text
📁 repositori
│
├── README.md
│
└── 📁 docs
```

---

## 5️⃣ Afegir el codi web

Copieu dins de la carpeta **docs** el codi corresponent a la pàgina web que voleu presentar al client.

Exemple:

```text
📁 docs
│
├── index.html
├── style.css
├── script.js
└── assets/
```

---

## 6️⃣ Guardar els canvis

Confirmeu els canvis realitzats i pugeu-los al repositori remot.

```bash
git add .
git commit -m "Afegida proposta web"
git push
```

---

# 🚀 Desplegament amb GitHub Pages

Una vegada el contingut estigui pujat a GitHub:

1. Accediu a **Settings**.
2. Entreu a **Pages**.
3. Seleccioneu la branca principal.
4. Configureu la carpeta:

```text
/docs
```

5. Deseu els canvis.

GitHub generarà automàticament una URL pública on es podrà visualitzar la web.
